# Letter from The Deep TAB5

**[English](README.en.md) | [日本語](README.jp.md)**

Copyright 2026 mochimochi-man / うっ ([X: @calorie0](https://x.com/calorie0))

ESP32-S3 と 320x240 の ST7789 パネルで動く海洋探索アドベンチャーゲームっぽいけどゲームではない何かです。

## ストーリー

> **ブリストル、1783年3月14日**
>
> **親愛なるフェンウィックへ**
>
> やあ、久しぶり。ちょっとした大発見をした。内容は書かない。書いたところで君は信じないし、
> 私としては君の顔を見てみたい。
>
> 本当はこの春に上がるつもりだったが、無理だとわかった。発見から出てきた研究が、
> ひと月も放っておけるものではなかったからだ。浮上と再潜航にかかる時間など論外だ。
> 手放す気はない。だから代わりに君に頼む。
>
> フローティング・ハーバーに舟を一隻、君の名前で入れてある。閉鎖循環式の船殻だ。
> 君の肝が続くかぎり、いくらでも潜っていられるものだ。これは贈り物だと思ってくれ。
> 厄介事だと決めつけないでくれよ。
>
> 私の居場所は書かないでおこう。書けば君はまっすぐ来てしまい、途中を何も見ない。
> 途中のほうがとびきり上等なのだ。古い石の門から降りて、気の赴くまま進みなさい。
> 見つけた廃墟はすべて手帳に控えること。ひとつ残らずだ。どれだけ馬鹿げて見えてもだ。
> 実際、それらは、まったく馬鹿げている。
>
> 手帳が埋まったとき、君は「ここが何なのか」を理解する。そして彼らは君を迎え入れるだろう。
>
> だが、私はここの眺めにも些か飽きた。迎えに来てくれ。
>
> 君がここに着くころには、私の研究も完了しているだろう。
>
> かつて君の師であり、いまは君のしもべである
>
> **S・メロウ**

## 必要なもの

- ESP32-S3 N16R8（フラッシュ16MB / PSRAM 8MB OPI）
- ST7789 SPI液晶 320x240
- USBゲームパッド **または** USBキーボード（USBホスト側に接続）

## ピン配置

ST7789（SPI 80MHz）

| 液晶 | ESP32-S3 |
|---|---|
| SCLK | GPIO12 |
| MOSI | GPIO11 |
| DC | GPIO9 |
| CS | GPIO10 |
| MISO | 未使用 |
| RST | 3.3V直結。GPIOに配線する場合は `lgfx_setup.h` の `PIN_TFT_RST` を変更 |
| BLK | 3.3V直結。GPIOで制御する場合は `lgfx_setup.h` の `PIN_TFT_BLK` を変更 |
| VCC | 3.3V |
| GND | GND |

## 書き込み設定

Arduino IDE

| 項目 | 設定値 |
|---|---|
| ボード | ESP32S3 Dev Module |
| Flash Size | 16MB |
| PSRAM | OPI PSRAM |
| Partition Scheme | Custom（同梱の `partitions.csv` を使用） |
| CPU Frequency | 240MHz |
| CDC On Boot | Disabled |
| USB Mode | Hardware CDC and JTAG |

WindowsではPowerShellを使って `tools/build.ps1` でビルドできます。

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

書き込みまで行う場合は

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Upload -Port COMxx
```

- ※イメージが大きく arduino-cli の書き込みが途中で止まるため、esptool を直接呼んでいます。
- ※ライブラリ **LovyanGFX** をインストールしてください。
- ※`arduino-cli.yaml` の `directories` は環境ごとに書き換えてください。

## 操作方法

USBに何も接続されていない場合、タッチパネル操作モードとなります。

| 入力 | 動作 |
|---|---|
| 画面中央より左側 | 前後・左右に移動 |
| 画面中央より右側 | 左右を向く・上下を見る |
| UP / DOWN | 浮上 / 潜航 |
| BOOST | 押している間だけ増速。 |
| ミニマップをタップ | 拡大マップ → モニュメント一覧 → 生物一覧 → 通常表示 |

### USBゲームパッド

| 入力 | 動作 |
|---|---|
| 左スティック / 十字キー | 前後・左右に移動 |
| 右スティック | 左右を向く・上下を見る |
| ボタン5 / ボタン6 | 浮上 / 潜降 |
| ボタン1（A） | 押している間だけ増速。メニューでは決定 |
| ボタン2（B） | メニューでは取り消し。都市でパネルを開いている間は帰還 |
| ボタン10（Start） | 拡大マップ → モニュメント一覧 → 生物一覧 → 通常表示 |

LogicoolのF310にあわせています。
機種によって設定が異なるため、ご自分の所有する機器にあわせてください。

### USBキーボード

| キー | 動作 |
|---|---|
| W / S（↑ / ↓ でも同じ） | 前進 / 後退 |
| A / D（← / → でも同じ） | 左 / 右に平行移動 |
| J / L | 左 / 右を向く |
| I / K | 上 / 下を見る |
| Q / E | 浮上 / 潜降 |
| スペース | 押している間だけ増速。メニューでは決定 |
| Esc（BackSpace でも同じ） | メニューでは取り消し。都市でパネルを開いている間は帰還 |
| Enter（Tab でも同じ） | 拡大マップ → モニュメント一覧 → 生物一覧 → 通常表示 |

### シリアル（115200bps・デバッグ用）

| キー | 動作 | キー | 動作 |
|---|---|---|---|
| `w` / `s` | 前後 | `a` / `d` | 左右 |
| `h` / `l` | 左右旋回 | `i` / `k` | 上下を見る |
| `u` / `o` | 浮上 / 潜降 | `x` | 推力と慣性を止める |
| `p` | メニューのカーソル移動 | `g` | 決定 |
| `q` | 取り消し | `v` | パネル切り替え |
| スペース | 一時停止 | `m` / `t` | 手動 / 遊覧カメラへ切り替え |
| `r` / `n` / `1`〜`5` | 自動遊覧に戻して移動 | | |

## 遊び方

海域を探索し、海底に眠るモニュメントを発見してください。

ゲーム中に START ※ を押すと、マップが開き現在の状態がセーブされます。
START ※ を押すごとにマップ→発見したモニュメント→発見した生物の順にトグルします。
※TAB5単体での操作方法は前述のとおりです。

セーブを消すにはタイトル画面の RESET を選んでください。
